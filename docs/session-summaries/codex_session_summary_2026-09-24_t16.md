# T16 导出预检与完整理由附页交接（2026-09-24）

在 `codex/v29-p1` 未提交工作区，年度榜单导出现在从实际 `planJournalPages` 返回的 `JournalRankSlot` 读取名称、艺人/评分行、理由裁切状态，并用渲染复用的封面加载路径判断文字占位。预检逐项列出名次、专辑和原因；可跳转到来源乐评编辑页，或定位并聚焦榜单对应理由。封面缺失只提示占位，仍能继续导出。

“附上完整入选理由分页”由同一分页函数按保存榜单顺序生成，保留原文换行、中文和 emoji。附页计入导航、缩略图、文件名总页数、全选、保存与分享；超过九页沿用原生分批分享。主海报仍保持原 5/5/5 青绿拼贴。隐藏正文时，理由裁切提示和附页同时消失；隐藏评分和日期沿用原图片逻辑，复制预检仅包含当前可见设置下的名次、专辑和原因。修改隐私或附页设置立即清空旧预检，待新规划完成后显示新页数。

`scripts/codex_check_rank_poster.mjs` 扩展了 1–15 张全场景、长中文/emoji/标题、两种主题、16 种隐私组合、缺封面、原文换行和顺序、复制脱敏、定位编辑、附页全选及下载文件名断言。代表预检和附页截图在 `release/codex_t16_visual_final_20260924/rank/`；已人工查看，附页正文与页脚没有越界。`release/codex_t16_full_20260924/codex_results.json` 为修改旧规划清理时机之前的 25/25 全量结果；该清理及最终测试修改后的受影响复测见 `release/codex_t16_replan_final_20260924/codex_results.json`。
