## 核查结论

首发建议 OPPO 个人移动应用通道：个人认证和新 APK 提审流程公开明确；个人页要求官方电子版权证书、个人免责承诺函与政策 URL，APP 备案及业务类目另须核对。华为 Android APK 路线可作为第二个核对渠道，不能将其当成原生 HarmonyOS NEXT 发布。华为同一 APK 文档前面的准备表与后文版权上传字段有差异：电子版权后文可选、手机版权/代理资料必选，应按 AGC 具体字段确认。

小米当前注册标准暂停接受新个人账号；vivo 个人上架限部分受邀体验；应用宝明确支持成年个人注册且有一般个人应用审核，但没有本人账号放行证据；荣耀支持个人认证，但资质页的公司名称匹配表述如何适用于个人仍未解释。

软件著作权官方登记费已停征、非经营性备案官方不收费；这不是所有电子版权证书/代办/托管/接入资源均免费的依据。六家里只取得小米明确基础发布平台免费条款，且该条款不解决个人准入。其余基础费用或电子版权实际价格未查得明确官方金额，未编造总预算。Google Play 海外路线一次性 US$25，新个人账号需12人连续加入封闭测试14天后申请正式发布。

产品主要缺口：没有首次隐私同意/拒绝；Android OCR 和 ML Kit 诊断数据披露不足；政策缺公开联系与权利信息；展示名仍为“私人音乐档案”；部分合并权限缺乏应用侧用途；16 KB RELRO 有静态问题；真机/OEM/升级/网络捕获仍待做。

补充数据流：表单、快速记录可自动读当前播放并请求 Apple；首页有重逢记录时也自动读取媒体，但不自动请求 Apple。播放器 `artworkUri` 会保存并进入 JSON 备份，可在快速记录页展示；HTTP/HTTPS URI 可能联网，本地 URI 不一概算联网。Apple 返回处理没有复制 Apple artwork URL。ML Kit 的本机 OCR 输入/输出与 SDK 诊断指标是不同范围；没有抓包，不报告实际未同意上传。
