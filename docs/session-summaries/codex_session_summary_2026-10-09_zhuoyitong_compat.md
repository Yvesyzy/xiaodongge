## 实际修改

1. NativeExport 的文件选择入口在 UI 线程捕获不可达异常，取消/失败都有回执；单文件回调检查丢失的 PluginCall，并在桥接工作线程完成解码、写入、flush/close。
2. 新增 Android API 29+ 的当前环境相册保存。只处理本应用生成的有效 PNG；文件名允许中文且拒绝路径/控制字符；pending 写入、完整关闭和成功发布后才返回 saved。失败只清理本次未完成 URI，清理未确认会明确提示，已发布文件不会因 JS 回执失败被删除。
3. 摘录卡和年记分页提供明确相册按钮；不擅自重定向原文件夹操作。状态说明兼容环境相册可能与系统图库分开，可使用卓易通文件互传。
4. 共享复制逻辑依次尝试原生、Clipboard API 和 DOM 回退；临时文本框处于当前模态框内，finally 移除并恢复焦点。备份、损坏原文、分享文字、榜单预检和诊断复用该逻辑。
5. 所有普通 NativeExport 文件保存调用统一校验 saved + 非空 URI；回执异常时不标记已保存、不更新备份健康，原文和预览保留。
6. 媒体会话服务缺失、通知访问查询/设置异常正常返回失败。诊断新增服务存在性与安全锁接口信息，并区分通知状态未知和未开启；不把接口存在当作实际读取/恢复成功。
7. 文件选择允许被兼容层误分类的 JSON，内容仍严格校验和隔离预演；缺安全恢复锁时提前禁用预演/导入/撤销，保留导出。核心日志、事务、独占锁和 generation 未绕过。
8. “更多 → 鸿蒙与兼容环境”离线说明覆盖文件互传、相册查找和当前播放替代操作。旧 WebView 保留 vh/宽度回退；系统文件/分享 Intent 通过 Android API 标准化带 charset 的 MIME。
9. 隐私政策与原生政策版本同步为 2026-10-09，说明主动相册保存。升级后会重新展示政策选择，现有记录保留，本地模式仍可导出。
