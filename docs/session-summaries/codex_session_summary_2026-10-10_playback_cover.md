## 实现

1. `NowPlaying.getCurrentTrack({ includeArtwork: true })` 从同一系统媒体会话按需返回顶层 `coverDataUrl`；首页无选项读取保持轻量，图片不混入音乐元数据。
2. `CodexNowPlayingArtwork` 读取专辑 Bitmap、媒体 Bitmap 或显示缩略图，并可回退到可访问的 content/HTTPS 地址。最大输入 4 MiB、URI 解码上限 20 MP、输出最长边 512 像素与 1,000,000 字节；保留长宽比，不回收系统拥有的 Bitmap。拒绝 file 路径、HTTP、URL 凭据和非标准 HTTPS 端口；重定向和本地地址检查受限。单个受限后台读取器为桥接提供最多 4.5 秒等待，阻塞的图片提供者不会无限占用桥接或不断新增线程。
3. 乐评和速记自动预览可解码图片。可选 `coverFromPlayback` 标记随既有草稿往返，兼容旧草稿和 JSON v6；无封面导出移除图片与来源标记。
4. 自动封面绑定作品身份；手动修改作品或切歌不会给新作品写入旧图。手动选图使旧封面响应失效。已有封面优先，自动保存使用条件插入；空格、大小写、全半角差异通过规范化回退识别，冲突时不擅自选择。
5. 隐私说明与原生政策版本同步为 2026-10-10，披露图片读取、草稿与本地保存；手动选图及仅本地模式继续可用。数据库结构未改。保留此前鸿蒙/卓易通未提交修改。
