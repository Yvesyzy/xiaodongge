# 简约年度总结交付

Yves 已确认本版定稿。最新设计以简约 V2 为准，重听对照与放映厅不在本轮新增范围。

## 可点击原型

入口：http://127.0.0.1:5174/codex-prototype.html

如果本地预览服务停止，在项目目录运行：

```powershell
npm.cmd run mobile:dev -- --port 5174 --strictPort
```

顶部可切换零记录、1篇、6篇、128篇、单月45篇、超长标题与正文。原型加载真实应用页面，演示数据只使用专用预览地址。已存在未标记数据或演示记录被修改、替换时拒绝覆盖。模拟入口与夹具未进入 mobile/dist 生产构建。

## 已实现

- `/summary`：封面、年度总览、作品阅读、原文摘录；查询参数保留年份、页面、作品和筛选条件。
- 年份和月份仍采用 `createdAt` 本地年月。歌曲、专辑计入；草稿不计入，月度/年度自述另列。
- 封面可选作品；真实封面缺失时使用文字占位，不加入虚构作品图片。
- 十二月柱形按统一线性比例绘制；未来无记录月份用横杠，与零记录月份区分。
- 20篇以内全部月份展开；更多记录按月折叠、显示更多月份，每月每次增加20篇。搜索、月份、顺序可组合，显示匹配数、展开数、全年总数。
- 原文入口继续连接已有记录详情与编辑。月报与原有听感分析保留在 `/summary/analysis`，选中年份可传入。
- 1080×1680 PNG：封面、年度概览、全年记录索引、作品全文；导出全年数据不受筛选/折叠影响。
- 全文按固定字号测量换行，长文继续分配新页，保留中文、emoji及组合字符。索引尽量避免一条名称与日期跨页。显示收录数、总页数、页码和已保存/已发起下载数量。
- 每次只渲染当前页图片，保存当前页或系统分享；翻页后旧图不可用新页码保存。浏览器不支持图片分享时下载，取消不作为分享成功。
