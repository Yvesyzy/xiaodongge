# 年度听感标本册：案例与升级方向

状态：2026-09-05 方案研究，未修改应用代码；以下设计属于提案。

## 判断

现版增加了统计和海报导出，但主要视觉语言仍是数字卡、词频横条、原句列表。需要补足作品封面、内容层次、时间变化、个人选编和阅读节奏。

推荐：以“私人音乐杂志”为主体，加一个可跳过的故事预览入口。每页一个明确主题，封面、原文和图表交替；所有统计都能回到来源。独立图片、朋友圈组图和收藏版文档使用同一份内容，分别排版。

## 已核查的公开案例

| 案例 | 官方事实 | 对小懂哥的设计启发 |
| --- | --- | --- |
| Spotify Wrapped 2025 | 提供月度艺术家排名变化、兴趣社群和特殊收听日回顾。Spotify 2026-02-10 财报披露该活动超过 3 亿参与用户、6.3 亿次社交分享。 | 把变化和记忆做成独立故事，每页可分享；传播规模不能单独证明某种视觉设计造成成功。 |
| Apple Music Replay | 同时提供月度统计、年度数据、里程碑、年度视听回顾与分享。 | 月报自然汇入年册；日常可看，年底可定稿。 |
| YouTube Recap 2025 | 最多 12 张卡片呈现兴趣、观看习惯变化和画像，支持保存分享。 | 控制每页的信息量，使用有顺序的章节。此处参考的是 YouTube 整体 Recap，不能全部当作 YouTube Music 独有功能。 |
| Letterboxd | 个人年度回顾与全年可访问的年度/历史统计并存；支持作品海报和背景个性化。 | 把作品作为视觉主体，同时保留可追查的收藏和记录档案。 |

## 三种方向

### A 私人音乐杂志（推荐）

纸张、封套、索引号、批注、封面墙构成统一编辑风格。正文提供目录和单页浏览；手机纵向阅读，导出按页排版。

适合精读、收藏与朋友圈组图。收益在于让每条乐评都有位置；开发重点是内容选择、版式和分页导出。

### B 年度故事放映厅

8–12 个可手动翻页的全屏场景：开场、作品、感受、转变、原句、年度私选、结束。动画用于揭示信息，支持跳过和减少动态效果。

适合短时间回顾和单页分享。开发重点是节奏、页面状态、移动端表现；深入内容通过“打开原文”承接。

### C 可探索的音乐展览

封面展墙、时间轴、曲风分区组成二维展厅，点击作品展开乐评，按月份、评分和情绪筛选。

适合记录积累较多后探索关联。开发和移动性能成本较高；首期不做三维漫游，少量记录优先使用 A。

## 推荐内容结构

| 章节 | 阅读内容 | 视觉形式与数据条件 |
| --- | --- | --- |
| 年度封面 | 年份、可编辑标题、选定原句 | 使用实际作品封面拼贴；没有封面使用排版封套。当前年份显示截止日期。 |
| 六次认真听见 | 所有正式音乐记录逐篇呈现 | 少量记录时每篇一个完整标本页：封面、艺术家、记录日、评分、原文节选。 |
| 我的年度私选 | 年度专辑、歌曲、惊喜、最想重听 | 用户确认获选作品；最高评分只作为建议依据，不能冒充用户亲选。 |
| 这一年的记录节奏 | 月份记录分布与月度代表作 | 十二月封面年历；空白月份保留，但不解释为没有听歌。 |
| 我在意音乐的什么 | 制作、词曲、原创性、共鸣 | 有评分才展示维度对比，并标注各维度样本数；缺失值不补零。 |
| 声音与感受 | 对音乐对象的评价及代表句 | 小型关系图/卡片，点击可看具体原文。只描述乐评中的词语，不据此判断心理状态。 |
| 我的看法怎样变化 | 同一作品初次与后续听感对照 | 双栏文字、评分变化与日期；没有追加记录就隐藏。 |
| 留在纸上的句子 | 用户选择的 3–6 段原文 | 引文页，自动节选保持原句，允许调整选择和隐私。 |
| 写给下一年的自己 | 年度自述和重听清单 | 由用户填写，明确区别于系统生成内容。 |
| 档案索引 | 本册所有收录记录及统计口径 | 能核对 ID/标题/记录日、收录数量；重听次数与乐评篇数分开。 |

## 数据与内容边界

- 已有：正式记录保存时间、正文、作品信息、封面存储、标签、情绪、自选评分、四维评分、后续重听感受。字段存在不代表每条记录均填写。
- 报告继续按正式记录首次保存的本地时间计算。专辑发行年份可用于展示作品年代，但不改变报告月份。
- 无依据的播放时长、实际播放次数、全平台排名不生成。
- 只有六条时以六篇精读为中心；有足够跨月数据再显示变化。章节数量由内容决定，不把少量记录扩写成大段虚构年度故事。
- 自动解读必须关联具体记录；推断与原文分开显示，允许用户修改或隐藏。
- 首期不需要把私人乐评上传到外部模型。若以后选择云端文学化改写，须另行明确服务、数据范围与授权。

## 分享与收藏

提供三种同源输出：单张作品/引文卡；用户选定的朋友圈组图（每张可独立阅读）；完整按页收藏版（PDF 为后续输出选项）。保留本轮 PNG 总览作为分享摘要。导出前可隐藏评分、日期、原文等内容，预览实际公开的页面。
