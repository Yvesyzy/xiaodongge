# 公众号出稿使用说明

公众号出稿支持在本地生成可编辑稿件、预览、复制和配图导出，已包含在v3.4.1(39)中，包名与长期发布签名沿用既有配置。

下载：[v3.4.1 APK](https://github.com/Yvesyzy/xiaodongge/releases/download/v3.4.1/codex_xiaodongge-v3.4.1-39.apk)，75,761,447字节。SHA-256：`41bdab470b40ff8ec63054d97f5b08ed6c77fdc645883016c74abdd99b7ae81a`。可覆盖安装同签名的较低版本；推文草稿仍须另外导出，安装升级不等于已纳入乐评备份。

## 使用

1. 打开一篇乐评的分享面板，选择“公众号稿”；已生成的月报／年报也使用同一个分享入口。年度专辑榜单的导出面板可以从已保存的入选理由生成文章。
2. 合编多篇时，进入“更多 → 公众号出稿”，勾选正式记录，调整上下顺序，再点“生成公众号稿”。可以筛选标题、专辑、音乐人和年份。
3. 编辑推文标题、署名、导语、各节标题与正文，检查右侧或下方预览。编辑只影响推文稿，不改原记录。隐藏评分、记录日期、小懂哥名称、导语和正文的设置统一作用于预览、复制和导出。
4. “复制标题”用于公众号标题栏；“复制排版正文”提供HTML和纯文字两种剪贴板内容。正文中的配图位置对应导出PNG，图片需在公众号编辑器另行上传插入。粘贴后的字体、间距等以实际公众号编辑器为准。
5. “导出稿件与配图包”生成ZIP，包含独立HTML、标题、纯文字正文、使用说明、1200×510横版封面与所选PNG配图。配图最长边不超过1024像素；横版封面是本工具的设计尺寸，可在后台裁剪。也可以单独导出HTML或横版封面，或通过系统分享把素材包发给电脑。

## 草稿与容量

推文草稿按来源组合自动保存在本机，关闭并重开同一组来源可以恢复。草稿只保存文字和选项，不重复保存大图，**不包含在原有乐评JSON备份中**；需要迁移时请另导出HTML或素材包。

保存失败会保留当前输入、显示错误，并在离开时要求确认。损坏或不匹配的旧草稿不会被自动覆盖；“从原文重新生成”经确认后只放弃这组推文草稿，原记录保持原样。正文超限不会静默截断：文字总量上限2MiB，排版剪贴板总量512KiB，导出文件或ZIP上限8MiB；超限时可减少配图、分篇或使用HTML导出。

## 边界与验证

这是本地排版工具，不需要公众号密钥，不联网改写，也不上传草稿或自动发布。个人公众号可自行在后台使用生成的内容；网易云／豆瓣作品跳转尚未实现。当前公开版本与校验信息见[v3.4.1发布说明](codex_v341_release_notes.md)。

开发检查：`npm.cmd run publication:test`、`npm.cmd run publication:check`（独立启动本机临时服务），以及完整工程和Android单测门禁。v3.4.1的31项工程检查、30项Android单测通过，25个public资源与3个平台资源和新构建逐字节一致。UI验证使用隔离合成数据，不读取日常浏览器或个人档案。Android系统剪贴板接收、文件提供器、微信实际粘贴和图片上传仍需手机及公众号后台验收；浏览器模拟结果不代表这些真机环节已通过。

安装包和完整验证范围见[v3.4.1发布说明](codex_v341_release_notes.md)。
