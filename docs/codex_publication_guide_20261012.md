# 公众号出稿使用说明

公众号出稿支持在本地生成可编辑稿件、预览，并导出或复制 Markdown 稿；原有的复制排版、HTML 导出、封面导出与配图包已移除，包名与长期发布签名沿用既有配置。

下载：[v3.5.0 APK](https://github.com/Yvesyzy/xiaodongge/releases/download/v3.5.0/codex_xiaodongge-v3.5.0-43.apk)，75,773,694字节。SHA-256：`2c41eb4a461800983fd07a1dfc179f43c73844984ec60607d96319b89d5522e4`。可覆盖安装同签名的较低版本；推文草稿仍须另外导出 Markdown 稿，安装升级不等于已纳入乐评备份。

## 使用

1. 打开一篇乐评的分享面板，选择“公众号稿”；已生成的月报／年报也使用同一个分享入口。年度专辑榜单的导出面板可以从已保存的入选理由生成文章。
2. 合编多篇时，进入“更多 → 公众号出稿”，勾选正式记录，调整上下顺序，再点“生成公众号稿”。可以筛选标题、专辑、音乐人和年份。
3. 编辑推文标题、署名、导语、各节标题与正文，检查右侧或下方预览。编辑只影响推文稿，不改原记录。隐藏评分、日期、小懂哥名称、导语和正文的设置统一作用于预览、复制和导出；「隐藏日期」会同时隐藏三项日期。
4. “导出 Markdown 稿”生成 `.md` 文件，在公众号后台「文档导入」上传（支持 doc/docx/markdown，不超过15MB）；也可“复制 Markdown 全文”，粘贴到编辑器后点「转换格式」。标题栏仍需单独填写，可从全文第一行 H1 复制。稿内专辑、歌曲、艺术家、总评以及三项日期——专辑/歌曲发行时间、首次收听时间、乐评记录时间——各自独立成段；各评分维度（制作/词/曲/人声/原创性/共鸣，含旧版词曲）按每三项合成一行，行内用“ · ”分隔，如「制作：9/10 · 词：8/10 · 曲：8.5/10」。这样既紧凑又不依赖公众号导入器不支持的硬换行；没填的日期显示“未填写”，与乐评详情页一致。「隐藏评分」会同时隐藏总评和所有维度。粘贴后的字体、间距等以实际公众号编辑器为准。
5. 稿内配图位置以文字标注，本地图片不会随 `.md` 导入，请在公众号编辑器自行上传。若系统文件选择器或分享在你的设备上不可用，展开出稿页「Markdown 全文」直接复制即可，这条路径不依赖任何系统组件。原有的复制排版、HTML 导出、横版封面导出与 ZIP 素材包按钮已移除。

## 草稿与容量

推文草稿按来源组合自动保存在本机，关闭并重开同一组来源可以恢复。草稿只保存文字和选项，不重复保存大图，**不包含在原有乐评JSON备份中**；需要迁移时请另导出 Markdown 稿。

保存失败会保留当前输入、显示错误，并在离开时要求确认。损坏或不匹配的旧草稿不会被自动覆盖；“从原文重新生成”经确认后只放弃这组推文草稿，原记录保持原样。正文超限不会静默截断：文字总量上限2MiB，导出文件上限8MiB；超限时可减少配图或分篇出稿。

## 边界与验证

这是本地排版工具，不需要公众号密钥，不联网改写，也不上传草稿或自动发布。个人公众号可自行在后台使用生成的内容；网易云／豆瓣作品跳转尚未实现。当前公开版本与校验信息见[v3.5.0发布说明](codex_v350_release_notes.md)。

开发检查：`npm.cmd run publication:test`、`npm.cmd run publication:check`（独立启动本机临时服务），以及完整工程和Android单测门禁。v3.5.0的工程检查集12/12、共享单测32/32、公众号模型单测11/11通过，28个public资源与3个平台资源和新构建逐字节一致。UI验证使用隔离合成数据，不读取日常浏览器或个人档案。Android系统剪贴板接收、文件提供器、微信实际粘贴和图片上传仍需手机及公众号后台验收；浏览器模拟结果不代表这些真机环节已通过。

安装包和完整验证范围见[v3.5.0发布说明](codex_v350_release_notes.md)。
