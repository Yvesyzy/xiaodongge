# 网易云／豆瓣跳转与公众号出稿可行性

日期：2026-10-12。Yves询问能否让小懂哥直通网易云音乐或豆瓣，以及一键生成公众号推文；已补充自己的公众号是个人主体。本轮核查可行性与官方能力，没有实施功能、上传稿件、发布文章、提交或推送。

## 推荐的首版范围

1. 在专辑/歌曲及乐评处提供“去网易云听”“去豆瓣看”入口，打开用户确认的对应作品链接。平台原始分享链接可以作为绑定来源；没有链接时应引导查找并确认，不按名称猜作品ID。
2. 在现有分享/导出入口增加“生成公众号稿”：用户选择单篇乐评、多篇听感、月度回顾或年度榜单，预览并编辑标题、正文结构、评分与日期的展示，复制正文并导出配图/排版稿。默认整理已选原文，不编造听感或音乐事实；AI润色若另加应独立选择并确认数据范围。
3. 用户在自己的公众号后台核对、上传图片并发表。第一版的本地出稿和作品跳转不依赖好友圈服务，也不要求用户先注册好友圈。

## 网易云与豆瓣的边界

已核实小懂哥有Android系统分享接收入口：`nativeSharedMusic.ts` 的原始分享文本保存在sessionStorage，`QuickCapturePage.tsx`将其显示为核对线索。当前正式音乐目录字段的 `catalogSource` 只声明Apple，不能把 `catalogTrackId`、`catalogAlbumId` 当成网易云或豆瓣标识；`mediaId`、`mediaUri`也必须按真实来源验证后使用。

网易云官方 `https://m.music.163.com/m/applink/` 页面明确提供已安装客户端时的打开提示，但这只证明其客户端入口，不证明所有手机都能直接落到指定歌曲/专辑或自动播放。豆瓣音乐官网提供真实作品条目链接。首版优先打开已确认的HTTPS作品链接，由系统和目标平台处理；客户端未安装或不接管链接时回到网页。精确落页与分享回跳须按目标客户端版本真机验证，不猜私有URL scheme。

如果“直通”指把乐评自动发布到网易云或豆瓣，属于不同能力。本轮没有核实小懂哥可获授权使用的官方发评接口，不能承诺已经可用，也不把自动登录、抓取私有接口或模拟发评当作默认方案。可以先生成用户可编辑的稿件，再由用户在目标平台完成发布。

## 个人公众号的实际选择

官方订阅号发布能力文档列出 `/cgi-bin/freepublish/submit` 等接口，并明确自2025年7月起个人主体、企业主体未认证及不支持认证的账号回收该页所列接口权限。因此，针对Yves已说明的个人主体账号，推荐“本地生成稿件 → 在公众号后台审阅发布”，不承诺官方API一键正式发布。

官方另有新增草稿等接口；不能将发布接口限制机械套到全部草稿接口，也不能凭服务号文档断言个人号可用。若日后接入草稿箱，应先核对该公众号后台实际权限，并通过授权服务端保管凭据。当前不需要Yves提供密码或密钥。

草稿API文档还明确正文图片须使用指定图片上传接口获得的URL、外部图片URL会被过滤，封面需要相应素材。因此“生成本地HTML”不等于“已上传一份带图的公众号草稿”；复制排版、封面/图片上传以及公众号编辑器实际保留的样式均需要验收。应用内打开音乐链接与公众号正文中的外链能力也不能等同，正文外链按实际账号/编辑器支持处理。

## 官方依据与未验证项

- [订阅号发布能力](https://developers.weixin.qq.com/doc/subscription/guide/product/publish.html)：个人主体发布接口限制。
- [草稿管理](https://developers.weixin.qq.com/doc/service/guide/product/draft.html)、[新增草稿](https://developers.weixin.qq.com/doc/service/api/draftbox/draftmanage/api_draft_add)：草稿、图片与素材要求；不是对个人号权限的保证。
- [网易云客户端入口](https://m.music.163.com/m/applink/)、[豆瓣音乐](https://music.douban.com/)：客户端打开提示与作品网页。
