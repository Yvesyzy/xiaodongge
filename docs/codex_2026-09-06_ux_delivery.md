# 五项体验改进交接

Yves 明确要求五项建议全部实施，尤其将五分制显示统一为十分制。本轮已经完成代码、界面和回归验证。

## 已完成

1. 首页使用原始十分制评分，移除除以二和五星展示；未评分单独显示。首页、详情和单篇分享卡以首次正式保存日期为主，详情保留明确标注的收听日期。没有修改评分数据或数据库结构。
2. 首页顺序为最近三条记录、草稿摘要、年度入口、其他分析。两行摘要、缩小封面、深绿文字与近白背景；装饰不覆盖正文。
3. 完整乐评表单正文前置，390×844 首屏可以开始写；评分、标签、日期、截图等补充信息默认折叠。保留所有表单字段、自动草稿、恢复与独立正式保存，去除类型名称中的技术后缀。
4. 年度可选择封面、最多三篇代表作品、对应原文摘句和120字寄语。AppData 使用 journal-edition:年度 键，并加入共享备份白名单及结构校验。刷新、备份保留精选；删除或修改来源后失效摘句不继续展示。无封面使用年份与文字排版，重复总览入口合并。
5. 图片导出使用固定底部操作、附近五页缩略图、勾选/全选/未保存页选择。隐私开关覆盖 PNG 正文、摘录、寄语、标签、评分及具体日期；年度/月度分布仍保留，界面已注明。原生多页可选文件夹保存，部分失败返回成功页并支持重试；系统多图分享每批最多9张。浏览器批量分享预先生成后再次点击，保留用户手势；不支持分享时提示下载。取消不误报保存成功。
