# 小懂哥 v3.0

v3.0 把 v2.9 之后的数据保护修补与五项新功能打入正式签名 APK。Android 包名仍为 `com.yves.musicarchive`，版本为 `3.0 (28)`，沿用既有发布证书，可覆盖已安装的同证书正式版；安装前建议先在旧版保存并回读一份 JSON 备份，不要卸载应用。

## 本版变化

- 修复当前播放读取的提示位置、通知访问撤销后的引导，以及过期目录补全覆盖正在编辑作品的问题。项目 Android36 模拟器已用官方网易云音乐 9.5.95 在线播放验证读取与表单填入。
- JSON 备份升级为 v6，包含有效草稿；旧 v1–v5 备份仍可导入且保留本机草稿。损坏数据可见并可抢救；恢复中断有回滚屏障。导入前可查看差异，并在隔离数据库中预演写入和回读。
- 统一首页、聚合、年记的作品计数；空年榜单可管理，评分控件可用键盘操作；大图 OCR 在桥接前与原生解码时受字节/像素双重限制。
- 专辑盲重听、跨年专辑轨迹、榜单导出预检与完整理由附页，以及本机诊断与脱敏复制。
- 年记等低频页面按需加载，离线中文字体改为 WOFF2；初始 JS 相比原基线减少 17.49%。

## 已知验收边界

冷启动 P90 与首次榜单预览没有达到项目原定的“相对旧版不恶化超过 10%”门槛；同机测量的宿主时序波动较大，尚不能判定单一原因。实体手机、实际 B 站、系统分享接收应用、TalkBack 和不同 OEM 组合没有完成现场验收。网易云模拟器通过不能证明所有手机的播放识别故障均已消失。旧版 APK 不能读取 v6 备份，回退时不要通过卸载重装清除本机数据。原 28 项逐项记录见[验收表](https://github.com/Yvesyzy/xiaodongge/blob/v3.0/docs/codex_v29_upgrade_acceptance.md)。
