# T12 按需加载与字体评估交接（2026-09-24）

在 `codex/v29-p1` 未提交工作区完成 T12 的代码优化和受控测试。`mobile/src/App.tsx` 用 React `lazy`/`Suspense` 延后加载年度年记、月度/年度听感页、记录详情的当日听感注记及分享弹层；情绪洞察计算模块只在打开洞察页时导入。首页的初始执行 JS 从 649,281 降为 528,505 字节（减少 18.60%），CSS 从 115,807 降为 95,513 字节（减少 17.52%）。项目 Android36 模拟器的首页资源记录在前后两版均只有入口 JS 与 CSS，没有榜单字体请求。

年度榜单改用从原字体无损转换的 WOFF2。Noto Sans SC 为 11,294,724→7,783,528 字节（减少 31.09%），30,890 个字符映射、字形顺序、OS/2 字重与可变轴逐项一致；Montserrat 数字字体为 5,344→4,400 字节（减少 17.66%），10 个字符映射与字重一致。原 WOFF 和两份 SIL OFL 许可原文保留在源码中。转换和校验脚本、生成报告见 `release/codex_t12_performance_20260924/codex_evaluate_fonts.py`、`codex_font_evaluation.json`。最终 APK 的 public 资源只有两份 WOFF2，没有旧 WOFF；原 WOFF 对照包首次三页预览为 4,300 ms，未带来可重复的导出收益。

性能基线使用同一项目专用 `codex_np1_api36` AVD、同一 WebView、关闭 Wi-Fi/移动数据、15 条合成专辑记录及 15 张年度榜单。`release/codex_t12_performance_20260924/codex_fixture.json` 保存确切数据。`scripts/codex_check_performance.mjs` 每版冷启与暖启各 10 次，记录 Android `am start -W`、WebView 首页就绪、首页请求、PSS，并在榜单页三次依次渲染 1–15 张专辑所在的三页预览。它测量的是图片预览生成，不包含系统文件选择器写盘或微信接收。
