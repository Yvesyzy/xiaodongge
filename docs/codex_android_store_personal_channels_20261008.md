# 小懂哥：个人发布渠道、材料与费用

核查日期：2026-10-08。已知条件：Yves 以个人发布，目前没有软著、APP 备案或商店账号。范围是中国大陆普通 Android APK；现有功能是本地音乐日记、播放信息读取、截图识别及目录/天气联网查询。

## 首发选择

建议先走 **OPPO 个人移动应用通道**。官方既给出个人认证权益，也给出创建应用、上传 APK、提交审核的完整流程，准入证据最明确。先在本人账号确认实际入口、业务类目和电子版权申请通道，再投入付费材料。这是本次渠道比较的建议，不是审核通过保证。[个人认证](https://open.oppomobile.com/documentation/page/info?id=13797)、[个人应用发布](https://open.oppomobile.com/documentation/page/info?id=13798)

华为 Android APK 通道可作为第二个核对渠道。应用宝也有个人注册和一般应用审核规则；vivo 个人上架受邀请范围限制；小米当前不接受新个人开发者账号。荣耀个人认证可用，但公开文档不足以确认个人新 APK 的全部资质条件。

小懂哥没有提供在线音乐播放或音乐作品分发的已验证功能，应如实说明是本地记录工具。OPPO、华为等的“音乐类”有额外资质要求；最终类目由平台按业务判断，不能为了减少材料填写不真实类别，也不能仅因名字涉及音乐就认定必须办理网络音乐经营许可。

## 具体材料包与办理顺序

1. **先统一产品身份。** 应用展示名当前仍是“私人音乐档案”，计划产品名是“小懂哥”；申请材料前统一名称规则。包名 `com.yves.musicarchive` 与长期签名保留。申请人使用 Yves 的法定实名，不能把聊天称呼当证件姓名。
2. **由 Yves 完成 OPPO 本人注册认证。** 官方清单包含本人证件、手持照、实名手机号和银行卡；敏感材料在官方页面提交。检查是否能创建移动应用、真实业务类目及电子版权官方入口。此步骤不用把证件号码或密码发到聊天。
3. **准备版权资料。** 国家软著可作为多渠道的长期准备：软件申请信息、程序源代码与说明文档、身份证明；按正式登记要求整理，不替 Yves 编造开发日期、权利归属或证件信息。OPPO 所列电子版权另按指定渠道办理。[国家版权局登记办法](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)
4. **确定 APP 备案接入路径。** 当前有 Apple、天气及 SDK 联网，不能仅因日记本地保存就直接走“纯单机豁免”。先确认分发平台是否受理；否则选择满足实际条件的接入商。准备主体、名称、图标、包名、签名及实际网络服务信息；不把第三方 API 域名当作自己拥有的域名填报。[工信部 APP 备案通知（政府转载）](https://www.hunan.gov.cn/zqt/zcsd/202308/t20230809_29456035.html)
5. **完成隐私与发布整改。** 具体问题见审查报告：首次同意/拒绝、Android OCR 和 SDK、公开政策与联系渠道、名称一致、权限最小化、16 KB 及真机数据升级验收。政策中说明导出和删除权利，按目标商店提供对应 URL。
6. **制作首发资料并提审。** 签名正式 APK、图标、截图、简介、功能与权限说明、年龄分级、个人承诺函、电子版权/软著及备案信息。OPPO 通用审核页列至少3张1080×1920截图；若个人提交页当前另有规格，制作时按实际页面复核。演示内容使用有权发布的图片和文字，测试说明解释通知使用权和离线手动记录路径。

软著办法里的审查期限是自受理起60日，不能写成60工作日或整个办理周期保证；APP 备案通知的20个工作日也以材料齐全、符合要求为前提。平台提审、补正和邀请资格都有独立过程，不给出“几天必上架”的承诺。
