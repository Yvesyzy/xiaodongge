# 六项评分与旧记录兼容

Yves 已要求直接实施：分享页修复一起进入新版；多维度评分为制作、词、曲、人声、原创性、共鸣，综合评分取六项算术平均。

沿用现有 0.5–10 分、0.5 步进的 `RatingSlider`，平均分保留一位小数。多维模式的总分使用原生 `output` 展示；单项评分保留原滑块与正负修饰符。六项完整时由渲染数据计算平均分并清除总分修饰符，不能独立覆盖总分。

新增字段明确命名为 `ratingLyrics`、`ratingComposition`、`ratingVocals`，类型为可选的 `number | null`，兼容既有记录与调用方。旧版 `ratingSongwriting` 保留，不自动拆分或复制；编辑界面展示旧版词曲分，详情中仍能查阅。六项不完整时保留原有总分与修饰符，并提示补齐后再取平均；仅查看或修改正文不改变旧分数。

SQLite 沿用已有的按列检查与新增可空列方式，三个新列只在不存在时添加，不重建表、不改旧分数。Web 读取、SQLite 读取和备份解析统一将缺失新字段视为空值。保存、恢复、回滚和撤销均包含三个新字段。备份继续使用版本 6，接受既有版本 1–6；旧草稿缺少新字段时保持兼容，新草稿保存全部六项。

方案选择：新增可空字段并保留旧词曲最符合手工修改要求；自动拆分旧词曲会假定用户判断，覆盖旧总分也不符合要求，因此不采用。

验收：六项平均分、边界值、只读总分、保存重载、草稿恢复、旧锁定及未锁定记录正文编辑、旧备份导入、新字段备份往返/回滚/撤销、旧 SQLite 表升级和分享页回归均通过。正式包使用原 `com.yves.musicarchive` 和现有正式签名，版本升级为 3.1.0（30）；只生成本地可覆盖安装的 APK，不执行手机安装或公开发布。
