# v2.7.1 阅读排版与轻新拟物改造

目标：解决手机长文贴边，将现有音乐手记的墨绿、暖纸色、黑胶元素统一为纸感内容与柔和实体控件。

设计比较：全屏强新拟物会让长文和密集列表失去层次；只给按钮加阴影不能统一界面。采用轻新拟物：内容平面、容器浅浮起、输入浅凹入、主要操作墨绿凸起、选中项内凹并保留颜色和字重。

## 范围与规则

- 基于当前 2.7.1-test.1 工作区，保留已有未提交的导航、封面与返回修复。
- 不新增依赖，不改存储、路由、业务流程、导出画布、版本号、签名和现有 APK。
- 配色：暖纸 #f2f1eb、阅读纸 #fffdf8、墨绿 #245448、正文 #24362e、次要文字 #5d6b62、琥珀 #a57529。深色阅读保留 #17211e 与 #e9e9dd。
- 阅读页统一左右 gutter 为 clamp(26px, 7vw, 40px)，内容外框最大 700px；正文保留原文换行，三档 15/17/21px，行高 1.95。工具栏返回维持无边框。
- 光源左上；小控件阴影 3px、容器 6px；按钮至少 44px，输入边界、焦点轮廓、危险操作颜色与禁用状态保留。减少动态效果设置关闭新增过渡。
- 首页保留纸张纹理、右侧黑胶、草稿与最近三条前置；列表减少嵌套投影；回顾保留简约目录和原文。
