# 阅读、回顾与分享实施计划

**目标：** 落实 Yves 已批准的回顾→阅读→分享流程，所有正式乐评支持摘录/全文图片/文字，年度和月度入口统一，阅读可返回原位置并继续。

**架构：** 复用 JournalExport、Canvas 分页、NativeExport 和已有 SQLite 数据，不增加依赖、不修改数据库结构。分享和年度阅读子任务在独立 Git worktree 完成，主任务串联 App 路由、月报与阅读状态；检查后逐文件整合。

**技术：** React、TypeScript、Canvas、Capacitor、Playwright；保持现有浅纸白/墨绿/暖棕风格、十分制、createdAt 归档口径。新增脚本与组件使用 codex_ 前缀。

- [x] 分享：`codex_ReviewShare.tsx` 提供 `ReviewShare({ entry, onClose })`；修改 `codex_JournalExport.tsx`、`codex_yearbookPages.ts` 支持单篇所有正式类型、浅/深主题、隐私、分页不截断及系统分享；默认摘录由用户选取连续原文，修改卡片不改原文；文字复制走 NativeExport。
- [x] 年度：`codex_YearbookPage.tsx` 统一年度/月度入口、分类数量、代表作品、来源可追溯的变化、少数据简化、独立编辑年记、分享入口；年度原文页通过统一 ReviewShare 分享；不重复现有分析算法。
- [x] 阅读：App 乐评详情右上分享/更多、删除移入更多、列表分享、保存后分享；复用组件管理字号/背景与返回/滚动进度；阅读页收起底部导航，目录/上一篇下一篇稳定；月报状态、更新失败保留原件和独立分享。
- [x] 验证：模拟 song/album/month/year、缺封面、空/长正文、隐私/原句校验、全文分页字符保留；0/3/6/128 年度数量；阅读返回列表筛选/滚动、续读、深色/大字、分享取消保留预览、原始备份不变。运行 typecheck、31 单测、对应浏览器回归和 Web 构建；保存三类实际页面截图和交接。无需本轮发布或重新签名 APK。

**验收原则：** 不伪造数据/来源，不静默截断全文，不把打开系统分享视为已发送；统计与精选更新不覆盖用户寄语；取消操作保留设置；用户原有 `.claude/`、换行状态和已删除历史文档不处理。
