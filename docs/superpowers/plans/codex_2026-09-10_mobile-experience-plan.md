## 实施前核对的实现（历史基线）

- mobile/src/App.tsx：TimelinePage 使用 EntryList；EntryList 当前没有封面展示区域。
- mobile/src/App.tsx：loadEntryCover 先取 song 封面，再回退 album 封面；inputToCoverTarget 只要有 songName 就优先保存为 song 封面，未先按记录类型区分。
- mobile/src/store.ts：专辑聚合按 album 封面键读取。上述差异可解释“记录显示图片、专辑展示占位图”的一种路径；尚未读取手机实际存储，不能断言两条受影响记录均由此造成。
- mobile/src/codex_ReadingTools.tsx：顶部同时显示返回按钮和标题，固定底栏包含目录、字号、浅深主题；详情页另在 App.tsx 中提供更多菜单。
- mobile/src/main.tsx 使用 HashRouter；MainActivity.java 当前只注册原生插件，没有项目自定义的返回保护处理。

- [x] 核对封面目标选择、封面键、聚合分组和页面重新读取的完整链路，分别验证存错归属和界面未更新两类问题。

验收：上传或替换专辑封面后，首页、时间轴、详情、专辑展示一致；退出重进仍一致；取消选图、读取失败或保存失败不会清空已有图片。

## 任务四：Android 返回与退出保护

涉及：mobile/src/App.tsx、mobile/src/main.tsx、现有编辑／复听页面；Android 接入先核对 MainActivity.java 和已安装 Capacitor 返回处理，再确定最小修改点。

采用统一返回顺序，不额外模拟覆盖屏幕边缘的滑动区域：

| 当前状态 | 一次系统返回的结果 |
| --- | --- |
| 键盘或系统选图界面打开 | 按系统行为先关闭当前输入／选择界面 |
| 应用菜单、设置、预览等浮层打开 | 关闭最上层浮层，保留当前页面 |
| 编辑中存在未保存内容 | 沿用草稿保存或离开确认；保存失败不直接离开 |
| 阅读、作品详情等子页面 | 返回来源页；无来源时返回所属目录 |
| 专辑、搜索、总结等顶层栏目 | 返回首页，避免在栏目历史中反复循环 |
| 首页 | 首次提示；限定时间内再次返回才离开应用 |

- [x] 建议首页首次返回显示短提示：**“再返回一次即可退出小懂哥”**；退出窗口为 2 秒。
- [x] 从子页回到首页的那次返回不计为首页首次退出请求。
- [x] 超时、进入其他页面或应用切到后台后，清除退出计时，避免后续误退出。
- [x] 左右边缘触发的系统返回与系统返回键使用同一规则；取消手势不得改变页面。
- [x] 多任务／最近任务操作交由系统处理，不把“侧滑停住”自行定义成清理后台，也不强杀进程。
- [x] 使用统一返回入口防止一次动作被原生和网页各处理一次；核对原有 popstate 及未保存保护，避免双重确认和重复后退。

验收：子页一次返回只退一级；菜单打开时先关菜单；首页首次返回不退出，2 秒内再次返回才离开；键盘、选图、草稿、外部入口、手势取消及应用前后台切换均分别验证。
