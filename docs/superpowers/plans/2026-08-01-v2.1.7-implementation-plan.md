# v2.1.7「再次听见」实施计划

依据：docs/superpowers/specs/2026-08-01-v2.1.7-relisten-quick-capture-design.md

## 约束

- 分支固定为 v2.1.7。
- 复用 ReviewEntry、ListeningMoment、EntryDraft、AppData 和 CoverImage。
- 不新增依赖、SQLite 表或备份版本。
- 不修改 .claude/。
- 非平凡逻辑必须有可运行检查。
- 功能完成后更新 package.json、package-lock.json、Android versionName/versionCode、README，并推送分支到 GitHub。

## 任务 1：基线与模块边界

- 运行现有 TypeScript、移动端检查和构建。
- 建立 musicIdentity.ts、quickCapture.ts、resurfacing.ts、relistenComparison.ts、shareCard.ts。
- 为纯逻辑模块建立单一 check-mobile-v217.mjs。

验收：现有基线通过，新检查能够由 package.json 调用。

## 任务 2：草稿模式和存储

- EntryDraft 增加 captureMode: quick | full。
- 旧草稿默认 full。
- 草稿列表暴露 captureMode 并显示快速记录。
- Store 增加公开、窄范围的 AppData 读写接口。
- Store 增加按 id 读取 ListeningMoment 的接口。

验收：草稿兼容、Web 存储和原生 SQLite 模拟检查通过；备份仍为 v5。

## 任务 3：快速记录

- 新增 /capture 路由和 QuickCapturePage。
- 复用当前播放解析与 Apple 元数据补全。
- 实现严格音乐身份匹配；单匹配提示再次听见，多匹配要求选择。
- 实现最近 6 个已保存情绪。
- 实现快速草稿自动保存与恢复。
- 实现展开为完整乐评且保留字段。
- 页面重新可见时复查当前播放；有输入时不覆盖。

验收：手动输入、当前播放预填、权限关闭、匹配分流、草稿恢复和正式保存均通过。

## 任务 4：今日重逢与盲听重评

- 实现确定性重逢规则和 daily-resurfacing 状态。
- 首页接入今日重逢卡。
- 新增 /relisten/:entryId 路由和 RelistenPage。
- 保存 ListeningMoment 后使用 moment 查询参数恢复揭晓。
- 实现评分、情绪、原文和日期的事实比较。

验收：30/90 天、周年 7 天、近期重听排除、当天稳定、删除后重算和刷新恢复均通过。

## 任务 5：本地记忆卡

- 使用原生 Canvas 生成快速记录卡和重听对比卡。
- 支持隐藏正文、评分、日期和应用名称。
- Web 使用对象 URL 下载。
- Android 使用 Filesystem 将 base64 PNG 写入 Documents。
- 无封面、长文本和 Emoji 安全降级。

验收：纯逻辑布局检查、Web 生成和移动端构建通过。

## 任务 6：集成与视觉

- 首页提供快速记下、完整乐评、再次听见入口。
- 详情页和歌曲聚合页接入再次听见。
- 沿用当前唱片档案视觉；新增“重逢唱片内页”作为唯一视觉签名。
- 保持 44×44 触控目标、键盘焦点、大字体和减少动态效果。
- 只拆出本版本新增页面，不全面重构 App.tsx。

验收：主要入口可达，无空白卡和阻断式错误。

## 任务 7：发布验证

- 运行所有 mobile:check:*、check:v1-reliability、typecheck、build、mobile:build。
- 执行 git diff --check 和提交前自审。
- 更新版本到 2.1.7，Android versionCode 从 9 单调递增到 10。
- 同步 package-lock.json。
- 更新 README 和发布说明。
- 提交到 v2.1.7，创建 v2.1.7 tag 并推送分支和 tag 到 origin。

验收：本地与远端分支、tag 指向同一最终提交，工作区只保留既有 .claude/。
