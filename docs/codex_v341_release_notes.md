# 小懂哥 v3.4.1：保留封面清晰度与公众号出稿

读取当前播放封面时，现在尽量保留播放器提供的图片清晰度：可访问原文件就保留原始字节，仅提供系统Bitmap时保持原尺寸并保存为PNG，取消512像素缩小与JPEG有损重编码。本次从GitHub的v3.2.0升级至v3.4.1，一并发布此前本地测试的公众号出稿和可选自部署好友圈。

## 封面读取

1. 选择同意增强功能，在Android系统设置授予通知使用权，并让播放器保持播放。
2. 在新建乐评或快速记录中点击“读取当前播放”，核对作品信息和封面后保存。
3. 封面随草稿保留，确认保存后补齐缺失的本地封面；已有封面不会被自动替换。

系统提供多张可用图片时优先选择较大候选，同尺寸时优先原文件。原文件字节和本地完整备份保持一致；切歌、修改作品信息或撤销权限后，旧图不会自动写给新作品。慢图片提供者仍受超时限制，已可用的同次Bitmap可作为回退；修复了连续快速读取偶尔漏图的问题。

安全限额为4MiB、2000万像素，超限跳过而不静默缩图。播放器只提供缩略图、未公开图片或地址不可访问时，无法取得未提供的高清源，可手动选图。对外分享配图仍按各功能的尺寸和体积限额生成。

## 公众号出稿

- 从单篇乐评、已生成月报／年报或年度专辑榜单的分享面板进入“公众号稿”；“更多 → 公众号出稿”支持多篇选择和排序。
- 编辑标题、署名、导语及各节正文，预览后复制排版正文，或导出HTML、1200×510横版封面与ZIP配图包。
- 编辑的是推文副本，原记录保持原样；隐藏评分、日期、应用名称和正文的设置统一用于预览、复制与导出。
- 推文草稿只保存在本机，**不包含在乐评JSON备份中**；迁移时请另导出HTML或素材包。

这是本地排版工具。图片需在公众号编辑器自行上传插入，文章由用户在后台发布；粘贴后的样式以接收编辑器为准。详见[公众号出稿说明](https://github.com/Yvesyzy/xiaodongge/blob/v3.4.1/docs/codex_publication_guide_20261012.md)。

## 可选好友圈

提供独立账号、邀请码申请与确认、好友可见动态、点赞和评论，以及系统文字分享。私人档案继续保存在本机，只上传用户主动发布的快照；退出或撤回隐私同意会清除本机社交登录状态。

好友圈仍为自部署测试功能，当前没有公共服务。Android需要配置自行部署的HTTPS根地址；本机双浏览器联调可使用`npm.cmd run social:preview`。服务端源码与部署说明随仓库提供，见[好友圈说明](https://github.com/Yvesyzy/xiaodongge/blob/v3.4.1/docs/codex_social_test_guide_20261010.md)和[服务端说明](https://github.com/Yvesyzy/xiaodongge/blob/v3.4.1/social/codex_README.md)。
