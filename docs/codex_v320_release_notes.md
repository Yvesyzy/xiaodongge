# 小懂哥 v3.2.0：系统播放封面自动提取

读取当前播放时，现在可以把播放器向系统提供的封面一起带入乐评或速记，随草稿保留，确认保存后补齐本地封面。已有手动封面优先；切歌或修改作品信息后，旧图不会自动保存给新作品。

## 使用

1. 安装 v3.2.0，选择同意增强功能，并在系统设置授予通知使用权。
2. 在音乐播放器开始播放，进入小懂哥的新建乐评或快速记录；也可点击“读取当前播放”。
3. 核对歌曲、专辑和封面，保存听感。封面保存在本机，手动选图入口继续可用。

系统没有提供可读取图片时，仍可手动选图。图片最长边处理为 512 像素，保留长宽比，不保证取得原始高清图。本版不增加后台持续收集功能。
