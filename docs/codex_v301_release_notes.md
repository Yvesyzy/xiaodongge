# 小懂哥 v3.0.1

这是 v3.0 的补丁版。Android 包名保持 `com.yves.musicarchive`，版本升为 `3.0.1 (29)`，发布签名不变。已安装同签名正式版可直接覆盖升级，不要卸载应用；安装前建议保存并回读一份 JSON 备份。

## 本版变化

- 当前播放读取成功时在按钮旁明确显示歌曲、专辑、歌手；无播放会话、未开启通知使用权或读取失败时也给出可见提示。专辑优先记录保留作为来源的歌曲名。读取仍取决于播放器提供处于播放状态的 Android 系统媒体会话。
- 完整乐评默认展开情绪、评分和曲风等补充字段，避免入口被收起后误以为功能消失。
- 新建草稿上限从 5 份增至 10 份；草稿箱与 v6 备份导入使用相同上限。
- 深色模式下统一乐评的曲风、情绪、评分及相关面板底色与文字对比度。

## 使用与验收边界

若当前播放无法读取，请在系统设置中开启小懂哥的通知使用权，保持网易云等播放器正在播放，再点“读取当前播放”。项目模拟器此前验证过官方网易云 9.5.95 在线播放时三字段可读取；本版的新增回归覆盖系统媒体会话、页面提示和表单填入，未重新完成网易云在线实播。实体手机、实际 B 站、其他 OEM、系统分享接收应用及 TalkBack 仍需现场验收。v3.0 的冷启动 P90 和首次榜单预览未达到原定性能门槛，本补丁版未重新测量，不能宣称达标。旧版 APK 不能读取 v6 备份；回退时不要通过卸载重装清除本机数据。
