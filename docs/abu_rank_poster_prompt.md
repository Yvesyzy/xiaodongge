# 年度榜单海报重设计 · 交付给外部模型的提示词

用途：换掉当前「深色底 + 金色」的榜单导出视觉。下方两版提示词共用同一套美术方向，
分别交给 **GPT-6（改代码）** 与 **GPT-Image-2.5（出设计稿）**。

---

## 0. 先说清楚要避开的「AI 味」

当前实现（提交 `90998a6`）的这些特征需要被明确禁止，否则模型会默认走回同一条路：

| 特征 | 为什么是 AI 味 |
|---|---|
| 深色底 + 金色强调 | 图像模型表达"高级感"的默认解，已被用滥 |
| 右上角径向辉光 | 没有光源的发光，纯装饰 |
| 巨大半透明年份水印 | 零信息量的大数字 |
| 字母间距拉开的英文大写眉标 | 中文产品里塞英文装饰字 |
| 金/银/铜奖牌色阶 | 榜单题材最刻板的解法 |
| 渐变 + 圆角 + 描边光晕 | 通用组件语言的堆叠 |
| 居中大标题 + 细线居中 | 对称构图的安全牌 |

**写提示词的关键**：不要用"高级、现代、精致、有质感"这类形容词——它们只会让模型回到上表。
要给**具体的现实参照物**（某种真实印刷品）+ **可检查的禁令** + **版式硬规则**。

---

## 1. 推荐美术方向：凸版印刷的唱片内页

参照物：**Reid Miles 为 Blue Note Records 设计的唱片内页**、**ECM Records 的内页说明**。

不是"复古做旧"，是**克制、真实、像一张印出来的说明页**。选它的理由：
语义贴合（唱片榜单 → 唱片内页）；约束具体可校验（两种墨、直角、无渐变）；中文排版能成为主角而不是装饰。

### 备选方向（如需换口味，只替换两版提示词里的「美术方向」段落，其余不动）

- **日本 CD 店 POP 标签 / 城市流行印刷品**：暖白底 + 网点 + 超大阿拉伯数字当栅格锚点 + 横向色条。
- **索引卡 / 图书馆目录卡**：横线格纸 + 等宽字体 + 打孔 + 表格式名次，几乎零装饰。
- **瑞士国际主义栅格**：无衬线 + 严格多栏 + 巨大的编号与极小的说明文字，字号落差不靠颜色。

## 2. 提示词 A —— 给 GPT-6（改代码）

> 直接整段复制。

```text
你在维护一个 Android 本地音乐记录 App（React 19 + TypeScript + Vite + Capacitor）。
任务：重新设计「年度专辑榜单」的图片导出视觉。

## 定位
- 文件：mobile/src/codex_yearbookPages.ts，导出 1080×1680 的 PNG（Canvas 2D）。
- 榜单导出入口是 drawRankPage()，由 renderJournalPage() 在 kind === "rank" 时提前分流。
- 只改榜单这一种导出。cover / overview / index / works 的绘制不要动。
- 现有的美术方向（深色渐变底 + 金色强调 + 巨大年份水印 + 字母间距英文眉标 + 金银铜奖牌色）
  已被否决，必须全部换掉，不要保留任何一项。

## 硬约束（不可协商）
1. 画布 1080×1680。正文区上边 y=420、下边 y=1560（页脚分隔线在 y=1590，左右边距 72..1008）。
   任何内容不得越出这个范围。
2. 每页 5 个条目槽位，槽高 h 必须满足 (1560 - 420) % h === 0；每页容量由实测高度推导，不要硬编码数字。
   15 张专辑 = 3 页。
3. 用现成的数据结构 JournalRankSlot { rank, name, meta, notes: string[], entry?: ReviewEntry }。
   name / meta 是单行（可能已被省略号截断），notes 是 2–3 行纯文本。
   单行标签的截断必须在分页阶段（planRankPages）完成，绘制阶段只负责画。
4. 封面来自 slot.entry，通过现成的 store.getEntryCover 异步取（返回 data:image/… 或空）。
   entry 可能不存在（原记录已删除），必须有占位分支，且占位不能是另一个"发光卡片"。
5. 中文为主，可能夹杂 emoji 与组合字符。字体只能用系统回退栈：
   "Noto Serif SC", "Songti SC", "SimSun", "Microsoft YaHei", "PingFang SC", system-ui。
   衬线用于标题，无衬线用于正文。
6. 禁用：外部字体文件、网络资源、DOM 叠加层。这是纯 Canvas 2D。
7. 必须继续尊重现有开关：hideBrand（隐藏应用名）、hideDate（隐藏整理日期）、
   hideRating（隐藏评分）、hideContent（隐藏入选理由）。必须保留页脚「第 i / n 页」。

## 美术方向：凸版印刷的唱片内页（Letterpress LP sleeve notes）
参照物：Reid Miles 为 Blue Note Records 设计的唱片内页；ECM Records 的内页说明。
目标是一张"真的被印出来"的说明页，不是一张"高级感海报"。

必须做到：
- 底色是未漂白的纸白（#F2EFE6 一类的暖白）。没有渐变、没有辉光、没有阴影、没有纹理噪点。
- 只有两种墨：主墨近黑（#14110E 附近），外加一个专色（建议砖红 #B23A2E 或墨绿 #1F4A3D）。
  专色只允许出现在三个地方：名次数字、1px 分隔线、页眉那一条横线。禁止使用金色。
- 全部直角，圆角只允许 0–2px。禁止圆角卡片、色块面板、投影、发光、描边光晕。
- 留白至少占版面的 25%。宁可少放装饰，绝不填满。

明确禁止（这些都是 AI 生成海报的典型特征，出现即算不合格）：
- 深色背景 + 金色强调；右上角径向光
- 巨大的半透明年份数字水印
- 字母间距拉开的英文大写眉标（形如 A N N U A L  T O P  A L B U M S）
- 金 / 银 / 铜奖牌色阶，或用圆形徽章包裹名次
- 渐变、投影、圆角卡片、居中对称构图

版式要求：
- 用一条明确的栅格：左栏放名次与封面，右栏放文字，两栏共享同一条基线。
- 字号阶梯要有大落差（最大字号与正文字号至少 2:1）。层级靠字号与字重建立，
  **不要靠颜色深浅**（不要用小灰字表示次要信息，用同墨色的更小字号）。
- 分隔线只有 1px 实线，只在条目之间，长度与文字栏同宽。不要虚线、不要装饰短线。
- 页眉只放必要信息：应用名 + 年份 + 「年度专辑榜单」。中文，不夹装饰性英文。
- 名次不要用"奖牌"语义。用印刷品的做法：等宽数字编号，或把名次数字放大成栅格锚点。

## 交付顺序
先只输出你的版式方案（栅格划分、字号阶梯与字重、两处颜色的具体值、留白比例分配），
不要写代码。等我确认方案后再实现。
```

## 4. 两个模型怎么配合

1. 先跑提示词 B 出 3–5 张风格稿，挑一张**版式和墨色都满意**的。
2. 把选中那张**连同提示词 A** 一起交给 GPT-6，让它照图实现，而不是自己另起一套方向。
3. 提示词 A 已包含验收清单，要求 GPT-6 自己写自检脚本验证：
   底色为浅纸感、整页金色像素数为 0、5 个槽位都有封面区块、文本不越出 72..1008 / 420..1560、
   15 张分 3 页，并落盘样张 PNG。

## 5. 当前代码的可替换范围

- 视觉集中在 `mobile/src/codex_yearbookPages.ts` 的 `drawRankPage()`、`drawRankCover()`、
  `clipRounded()` 与文件顶部的 `RANK_*` / `COVER_RANK` 常量；
  数据结构 `JournalRankSlot`、分页逻辑 `planRankPages()`、封面缓存、隐私开关都可以原样复用。
- 现有自检 `scripts/abu_check_rank_poster.mjs` 的断言与旧配色绑定（例如"金色标尺""底色亮度 < 40"），
  换方向时要同步重写这些断言，否则会拦下正确的新设计。
- 交接文档见 `docs/session_summary_2026-09-15-abu-rank-poster.md`。
