# 小懂哥 v2.1.7

v2.1.7 把“记录音乐”从只写完整乐评扩展为两个连续动作：当下用 60 秒留下真实听感，过一段时间再盲听同一首歌，最后揭晓评分、情绪和文字如何变化。所有匹配、重逢选择、图片生成和状态保存都在本地完成。

## 快速记下

1. 首页新增“快速记下”入口，保留“写完整乐评”。
2. 原生端进入页面时读取当前播放，并尝试用 Apple Music 目录补充封面和元数据；Web 端可直接手动填写。
3. 最低保存内容只有歌曲身份、一句话感受和收听日期；评分与情绪均可留空，不制造缺失数据。
4. 最近使用的情绪优先展示，也可展开全部情绪。
5. 自动保存独立的快速记录草稿；可随时无损展开为完整乐评。
6. 写作过程中检测到歌曲变化时不覆盖当前输入，用户可保存草稿后再切换。
7. 保存前执行严格歌曲身份匹配：优先比较双方都有的目录曲目 ID，否则比较标准化的歌曲和歌手，并在双方都有专辑时要求专辑一致。
8. 命中已有档案时优先进入追加听感，也允许明确新建另一篇乐评。

## 今日重逢与盲听重评

1. 首页每天确定性选择一首至少 30 天前的歌曲，优先周年附近、久未重听和高评分记录；当天固定结果，支持“今天略过”。
2. 最近 30 天已有追加听感的歌曲不会再次出现。
3. 原生端当前播放恰好命中今日歌曲时，首页会合并提示，不创建第二个入口。
4. 盲听页提交前隐藏旧评分、旧情绪和旧正文，避免过去判断影响这一次。
5. 保存后才揭晓两次记录的间隔天数、评分变化、保留/新增/淡出的情绪，以及两段原文。
6. 未保存时，关闭或刷新页面会触发浏览器提醒；点击应用内导航会显示明确的继续填写/放弃离开选择。

## 本地记忆卡

1. 新增快速记录卡和重听对比卡两种 1080 × 1440 PNG。
2. 图片使用原生 Canvas 生成，不新增第三方依赖，不上传正文或封面。
3. 可独立隐藏正文、评分、日期和“小懂哥”名称。
4. Android 保存到 Documents，Web 端直接下载。

## 数据与兼容

1. 复用现有 `ReviewEntry`、`ListeningMoment` 和 `AppData`，不新增 SQLite 表，不提高备份版本。
2. 今日重逢状态随 v5 JSON 备份导出与恢复；旧 v1 至 v4 备份继续兼容。
3. 草稿增加 `quick` / `full` 模式；旧草稿缺少该字段时按完整乐评读取。
4. 保留 v2.1.6 的综合分锁定持久化和原生 SQLite v5 迁移可靠性检查。
