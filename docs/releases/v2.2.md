# 小懂哥 v2.2

v2.2 修复 Android 备份页导出无反应的问题，改用系统原生能力保存、分享与复制；同时换上贴合 App 主题的新启动图标。

## 新功能

- 备份页导出拆成三个明确入口：**保存到文件夹**（系统文件创建器，可自选目录）、**系统分享**（真实附件 + 对应 MIME 类型）、**复制内容**（Android 原生剪贴板）。
- 导出按钮下方实时反馈：处理中、成功、已取消和精确错误；系统窗口打开期间禁止重复点击。
- JSON 备份健康状态只在 Android 系统确认写入成功后更新；Web 下载不再被误记为确认保存。
- 新启动图标：深绿渐变 + 米白黑胶唱片 + 琥珀标签 + 音符，与 App 主题一致（自适应图标，兼容各厂商遮罩）。

## 修复

- Android 上「保存/分享文件」和「复制内容」此前走 WebView 接口无可见结果，现全部改用原生 API（`ACTION_CREATE_DOCUMENT`、`ACTION_SEND`、`ClipboardManager`）。
