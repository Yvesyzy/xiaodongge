# 小懂哥 v2.1.0

v2.1.0 把原有年度 Markdown 总结升级为“私人听感标本册”。核心分析完全在手机本地完成，不统计收听时长，不调用在线 AI，不上传乐评正文。

## 新增

1. 本地语义分析：识别音乐感受、音乐对象、表达方式和曲风，支持分句、最长词优先、否定、程度词和转折权重。
2. 可核查证据：每个重点词显示出现次数、涉及乐评数和可返回原记录的证据句。
3. 乐评内每日注记：只有存在精确听感日期的歌曲或专辑乐评才显示，并合并同一天的多篇评价。
4. 中国大陆日期分类：普通工作日、调休工作日、普通假日和节假日；节日标签独立展示。
5. 天气背景：用户手动选择城市后按乐评日期缓存历史天气；离线和远端失败不阻止总结。
6. 月度听感作品：十二个月各有独立主题、构图和配色；人工“本月自述”单独展示。
7. 年度私人听感标本册：组合月度结构化结果和无月份乐评，避免重复分析生成文案。
8. 审美迁徙：在满足数据阈值时展示新出现、持续和渐隐的感受或关注对象。
9. 生活背景关系：仅在样本量达到阈值时比较工作日/假日和天气组，并明确不代表因果。
10. 代表原句：系统提供代表句，用户可手动设为月度或年度首句。
11. 本地语义校正：可排除误识别词，或将其调整到正确类别。
12. 数据量降级：少量记录显示记忆卡或精简年鉴，数据不足的趋势章节自动隐藏。
13. 统一交互与视觉：一个页面一个主操作，适配手机与桌面宽度，保留大触控区域和减少动态效果设置。

## 隐私边界

- 不读取个人日程，不申请系统日历权限。
- 不持续定位，不读取 vivo 私有天气数据，不申请定位权限。
- 天气请求只包含手动选择城市的粗略坐标、日期、时区和必要查询参数。
- 乐评正文、标签、情绪和评分不会发送给天气服务。
- 天气、节日和日期只作为背景，不用于心理诊断或情绪因果判断。

## 数据与兼容

- 保留 v2.0.1 的乐评、封面、搜索、聚合、可视化、导出和现有年度总结内容。
- 旧年度总结继续可读，重新生成后升级为结构化标本册。
- JSON 备份升级为 v3，并继续接受 v1、v2 备份。
- 新备份包含月度作品、结构化年度结果、天气设置和缓存、代表原句与语义校正。
- 乐评或设置变化时保留旧作品并标记待更新，不会删除用户内容。
