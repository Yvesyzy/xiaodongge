# 小懂哥 v2.3

v2.3 修复备份导出与导入的闭环问题、撤销快照超过浏览器存储上限的问题，对齐 Web 端与原生端的读取容错，并为本地分析规则建立单元测试护栏。

## 修复

- **备份导出/导入闭环**：此前导出的 JSON 包含设备本地状态（backup-health:v1），而导入白名单未包含该键，导致导出的备份无法再导入。现在导出时过滤该键（不属于用户数据），导入白名单同时兼容旧备份。
- **撤销快照存储上限**：导入备份前的撤销快照此前存 WebView localStorage，大备份会超过 5MB 配额导致撤销失败。现在原生端改存 SQLite 单行表 `UndoBackup`，Web 端仍用 localStorage。
- **Web 读取容错对齐**：原生端单条损坏数据只跳过该条、不阻塞整列表；Web 端此前会整体失败。现在两端一致：单条损坏跳过并告警，备份导入仍走严格校验。

## 维护

- 清理死代码：`shared/visualizations.ts`、`shared/moods.ts`、`mobile/src/listeningYearbook.ts` 未使用导出与恒真表达式。
- `DEFAULT_PRIVACY`、`downloadBlob` 下沉到 `mobile/src/shareCard.ts` 单一来源，删除两个页面的重复定义。
- 新增三套 `node:test` 单元测试（零新依赖）：语义分析规则（否定/程度/转折分句/配对/引用）、日期与天气规则（2025–2027 节假日与调休、天气码分类）、备份解析链（白名单/损坏容忍/语义校正校验），共 23 个用例。
