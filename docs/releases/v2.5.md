# 小懂哥 v2.5

年度总结改为简约的私人音乐杂志，补齐报告日期、草稿保存和分页图片导出。

## 安装前必读：本版更换签名

原签名文件未能找回，Yves 已授权使用新的长期签名。本版**不能直接覆盖安装 v2.3 或更早版本**。

1. 在旧版备份页导出 JSON 到应用外，确认文件可读取、记录数量正确。
2. 保留好备份后，卸载旧版并安装本版 APK；未确认备份前不要卸载。
3. 导入 JSON，核对乐评、封面和草稿，再继续使用。

后续继续使用本次新密钥发布的版本，可以覆盖升级 v2.5。不要把签名密钥或密码文件发送到 GitHub。

## 更新内容

- 年度音乐杂志：封面、十二月总览、作品全文及完整来源索引；支持零记录和大量记录布局、搜索、月份筛选及分批展开。
- 封面、总览、来源索引和长篇乐评可按 1080×1680 PNG 分页预览、逐页保存或系统分享。
- 月度/年度统一按记录创建时的本地日期归档；修复月报生成后不可见、年度来源遗漏与失败月份被静默跳过的问题。
- 首页文字增加清晰衬底，显示草稿数量；新建菜单包含完整、速记、草稿三个入口。
- 正文未填写时可独立保存草稿，恢复时保留原记录模式。
- 包含前一阶段的备份导入/导出闭环修复和 SQLite 撤销快照。

## 验证
