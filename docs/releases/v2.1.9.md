# 小懂哥 v2.1.9

v2.1.9 把 Android 记录主路径改成“先认出专辑，再留下一句话感受”。已有歌曲记录和旧草稿保持原类型，不做批量迁移。

## 新功能

- 当前播放识别到专辑时，新记录默认使用 `album` 类型，标题使用专辑名；触发识别的歌曲保存在 `musicMetadata.displayTitle`，不会丢失来源。
- 快速记录改成一屏主路径：专辑卡、一句话感受、收听日期、保存；评分、情绪和音乐信息收进补充区域。
- Android 注册 `ACTION_SEND / text/plain` 分享入口。从其他应用分享后直接打开速记，原分享文字只用于核对，不猜测第三方私有文本格式。
- 底部主导航改为首页、专辑、新建、搜索、总结；时间轴移到“更多”。
- 备份页新增健康检查，实际生成 SQLite v5 JSON，记录数量、字节数、SHA-256 和最近验证时间；成功写入 Documents 后单独记录最近保存时间与文件名。
- Web 本地 JSON 损坏时先把原文隔离，再移除损坏键并明确报错，避免静默回退为空数据后覆盖原记录。

## v2.1.8 审查修复

- 关闭 Android 系统云备份，统一隐私说明与 Manifest 行为。
- BottomSheet 打开后聚焦弹层内容，限制 Tab 焦点，支持 Escape 关闭并恢复触发按钮焦点；路由变化自动关闭。
- 损坏 localStorage 不再静默吞错，备份页可以复制或手动清除隔离原文。
- release 构建不再接受 `app-release-unsigned.apk`；缺少长期签名变量时直接失败。
