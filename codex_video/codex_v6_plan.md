## 设计

主线：「把听过，变成记得」。选择有情绪推进的品牌叙事，利用真实UI证明记录、重听和年记；音乐从留白的钢琴进入律动，在重听前收低，年度海报段形成高潮，最后留出3.6秒品牌收束。

| 时段 | 内容与镜头 | 音乐 |
|---|---|---|
| 0–4.8秒 | 声音会过去，感受值得留下；唱片环、封面与文字层次 | 留白、空间感钢琴与轻微纹理 |
| 4.8–9.6秒 | 第一次听见；封面聚合进入真实档案卡 | 旋律建立、低音渐入 |
| 9.6–16.8秒 | 真实速记、输入、保存；一句话成为记录 | 鼓组与保存重音 |
| 16.8–25.2秒 | 评分、情绪；19.2–24秒大类→电子→House→Deep House；六项评分 | 持续律动和三级操作重音 |
| 25.2–33.6秒 | 实际全局深浅、独立阅读深浅按钮 | 清晰切换音效、和声变化 |
| 33.6–39.6秒 | 223天后，隐藏旧评价，先写此刻 | 降低伴奏，保留呼吸感 |
| 39.6–42秒 | 实际8→9.5及听感对照 | 旋律回归、揭晓重音 |
| 42–46.8秒 | 月份累积成时间与音乐档案 | 逐层加密 |
| 46.8–51.6秒 | 年记封面及真实年度统计 | 弦乐与高音旋律抬升 |
| 51.6–56.4秒 | 15张原创封面汇入三张真实年度海报 | 高潮、合拢重音 |
| 56.4–60秒 | App图标、品牌句、简洁结束 | 终止和弦与自然淡出 |

横版1920×1080，竖版1080×1920，30fps、1800帧。时间表100 BPM，一拍18帧，曲风修订后38个同步事件。原有50张截图沿用已验收的3.1.1快照；另补拍4张当前3.1.1真实曲风控件，使用同一份虚构演示数据，不重画控件。全局和阅读开关独立；Top15是个人选编，海报保持真实导出模板。
